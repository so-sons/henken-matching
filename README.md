# 偏見ゲッサー

出題者がこっそり決めたお題（キャラ・有名人・身近な人など何でもOK）を、回答者が「〇〇そうですか？」と偏見をぶつけて当てる対戦ゲーム。
イナゲッサー（https://github.com/so-sons/inaguesser）の「質問モード」をベースにしています。

- お題：出題者が自由に入力。ジャンル（任意）を付けると回答者に表示
- 偏見：「　」そうですか？ の空欄を埋めて質問（回数はルームで 無制限／10〜30回）
- 自由質問：偏見に関係なく何でも聞ける（ルームで 2〜5回）
- 回答：お題を答える（ルームで 1〜5回）。お題と同じ文字なら自動で正解、それ以外は出題者が「正解／惜しい／不正解」で判定
- 通信は PeerJS（WebRTC）。サーバー不要。静的ファイルだけで動きます
